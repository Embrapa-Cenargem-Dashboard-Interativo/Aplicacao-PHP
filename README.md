# Embrapa Cenargen - Aplicação PHP

Repositório destinado ao desenvolvimento e à **validação das regras de negócio do Sistema de Gestão de Campos Experimentais da Embrapa Cenargen (CVGWeb)**.

## Sobre o projeto

Este repositório concentra uma implementação em **PHP** utilizada para testar e validar o funcionamento das principais regras de negócio da aplicação.

O desenvolvimento ocorre de forma experimental, permitindo que as funcionalidades sejam implementadas e avaliadas junto ao **stakeholder**, verificando se o comportamento do sistema está de acordo com as necessidades e processos definidos para o gerenciamento dos espaços experimentais.

## Principais objetivos

O repositório será utilizado para:

* Implementar regras de negócio do sistema;
* Testar diferentes comportamentos e fluxos da aplicação;
* Validar as funcionalidades junto ao stakeholder;
* Identificar possíveis ajustes ou necessidades antes da implementação definitiva;
* Experimentar soluções para o gerenciamento de pesquisadores, projetos, espaços e reservas;
* Servir como ambiente de apoio para a definição e validação dos requisitos do sistema.

## Tecnologia

* **PHP** - linguagem utilizada para o desenvolvimento e implementação das regras de negócio.

## Objetivo do repositório

Este repositório tem como finalidade servir como um **ambiente de desenvolvimento e validação**, permitindo que as regras de negócio sejam testadas na prática e ajustadas de acordo com o retorno do stakeholder antes de serem incorporadas à aplicação principal.
